# My Recipe Book

Chris's personal recipe app: every dish in Basic, Intermediate and Advanced versions, written for an electric hob, air fryer and microwave. Installable on Android and works offline.

- `index.html`, `style.css`, `app.js` – the app
- `recipes.js` – recipes, calorie table and Kitchen basics
- `sw.js` – offline support (bump `VERSION` after each change)
